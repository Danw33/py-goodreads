# Security policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing credentials, session cookies, private profile
data, or a working exploit.

This client does not accept Goodreads credentials and does not implement write
operations. Reports about Goodreads itself should be sent to Goodreads or
Amazon through their own security channels.
